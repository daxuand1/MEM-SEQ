# MEM-SEQ
MEM-SEQ is a fast and scalable framework to select spatial eigenvectors from Moran's Eigenvector Maps (MEM) theory to adjust for spatial autocorrelation in spatial microbiome analysis.

This repository contains simulation/example code for the MEM-SEQ framework.

Functions.R - function library, including various eigenvector selection methods and simulation functions.

Simulation.R - simulation main function.
